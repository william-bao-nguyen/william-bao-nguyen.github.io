SLAC National Accelerator Laboratory

Beam–beam effects in linear colliders

As a SULI intern at SLAC, I worked under Professor Spencer Gessner as part of the multi-TeV beam–beam working group. I validated and benchmarked quantum-physics packages in the particle-in-cell code WarpX for linear-collider applications.

The results showed agreement with the established beam–beam code GUINEA-PIG while demonstrating a path toward more scalable large simulations. Read the IPAC ’24 proceeding.
